# راهنمای مستندات پروژه (جدول مسیر)

این فایل نقشه راه مستندات پروژه **«پیرایش عارف»** است. در این مستندات سه اصل رعایت شده است: **فقط وضعیت فعلی برنامه** نوشته شده، **هر واقعیت فقط در یک فایل** قرار دارد، و **هیچ کدی در مستندات کپی نشده است**.

## برای هر کار، کدام سند را بخوانیم؟

| نوع کار یا سوال | سند مرجع | توضیح محتوا |
|---|---|---|
| شناخت کلی محصول، کاربران، قوانین کلی و طراحی ظاهری | [product/PRD.md](product/PRD.md) | هدف برنامه، نقش‌های کاربری (مشتری و صاحب آرایشگاه)، قوانین کلی محصول و استاندارد فونت و رنگ‌بندی |
| شناخت بخش‌های فنی پروژه و نحوه ارتباط آن‌ها | [architecture/overview.md](architecture/overview.md) | ساختار فرانت‌اند، بک‌اند و دیتابیس و چگونگی ارتباط و تبادل داده بین آن‌ها |
| کار روی بخش نمایش و مدیریت خدمات آرایشگاه | [features/services.md](features/services.md) | مشخصات فیچر خدمات، نمایش خدمات فعال به مشتری و افزودن، ویرایش و غیرفعال‌سازی خدمات توسط صاحب آرایشگاه |
| کار روی بخش حساب مشتری و فرم ثبت نوبت | [features/booking.md](features/booking.md) | مشخصات فیچر ورود مشتری، فرم رزرو نوبت، انتخاب تاریخ و ساعت و قوانین ثبت نوبت |
