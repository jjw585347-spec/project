# سیستم نوبت‌دهی آرایشگاه «پیرایش عارف»

این پروژه سیستم نوبت‌دهی آنلاین آرایشگاه است و از دو بخش تشکیل شده است:

| پوشه | بخش | تکنولوژی | آدرس اجرا |
|---|---|---|---|
| `backend` | بک‌اند و API | Laravel (PHP) + PostgreSQL | http://localhost:8000 |
| `frontend` | رابط کاربری (فرانت‌اند) | React + Vite | http://localhost:5173 |

---

## قانون کار ایجنت (هوش مصنوعی)

> **مهم:** قبل از شروع به حل هر مشکل اول ریشه‌یابی می‌کنی، بعد نقشه می‌دهی و بعد منتظر مجوز من می‌مانی و بعد از گرفتن مجوز از من شروع به حل آن می‌کنی. (تمامی قوانین در فایل [AGENTS.md](AGENTS.md) قرار دارد.)

## امکانات پروژه

- **طراحی و رابط کاربری:**
  - کاملاً راست‌چین (`RTL`) با فونت `B Nazanin` توکار (بارگذاری مستقیم از پوشه `frontend/public/fonts` تا در موبایل، مک و ویندوز تغییر نکند).
  - پس‌زمینه سفید (`#ffffff`)، دکمه‌ها و هدرهای سبز (`rgb(13, 101, 45)`) و متون تیره خوانا (`#111827`).
  - مجهز به تقویم شمسی و نمایش فارسی اعداد و قیمت‌ها.
  - نمایش پیام خطای فارسی واضح در صورت خاموش بودن سرور بک‌اند.
- **بخش مشتری:**
  - ایجاد حساب و ورود مشتری با نام، شماره موبایل معتبر ۱۱ رقمی (`09...`) و **رمز عبور ۴ رقمی عددی**.
  - امکان ثبت‌نام افراد مختلف حتی با نام‌های مشابه (تفکیک حساب‌ها بر اساس شماره موبایل یکتا و رمز ۴ رقمی).
  - اتصال مستقیم هر نوبت به حساب مشتری (`customer_id`) بدون نیاز به تایپ مجدد نام و شماره موبایل در فرم رزرو.
  - انتخاب ساعت نوبت از طریق **کارت‌های کوچک قابل کلیک** در بازه‌های ۳۰ دقیقه‌ای (از ساعت ۱۰:۰۰ تا ۲۰:۰۰) به همراه بررسی دقیق ساعت کاری در بک‌اند.
- **بخش صاحب آرایشگاه:**
  - مشاهده لیست نوبت‌های هر روز به ترتیب ساعت با انتخاب تاریخ از روی تقویم شمسی.
  - دریافت تأیید از صاحب آرایشگاه قبل از لغو نوبت و **تازه‌سازی خودکار لیست نوبت‌ها** بلافاصله پس از لغو.

## پیش‌نیازها (برای اجرای پروژه روی کامپیوتر جدید)

1. **Node.js** (برای اجرای فرانت‌اند)
2. **PHP** و **Composer** (برای اجرای بک‌اند لاراول)
3. **PostgreSQL** (ساخت یک دیتابیس خالی با نام `barbershop`)

---

## راه‌اندازی اولیه (فقط بار اول روی سیستم جدید)

### ۱. آماده‌سازی بک‌اند و دیتابیس
وارد پوشه `backend` شوید، پکیج‌ها را نصب کنید و فایل تنظیمات `.env` را از روی `.env.example` بسازید:

```powershell
cd backend
composer install
copy .env.example .env
php artisan key:generate
```

تنظیمات اتصال به PostgreSQL از قبل در فایل `backend/.env.example` قرار داده شده است:
```env
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=barbershop
DB_USERNAME=postgres
DB_PASSWORD=postgres
```
*(فقط اگر رمز PostgreSQL شما روی کامپیوترتان چیز دیگری است، مقدار `DB_PASSWORD` را در فایل `backend/.env` ویرایش کنید.)*

سپس جداول دیتابیس و لیست خدمات اولیه را بسازید:
```powershell
php artisan migrate --seed
```

### ۲. آماده‌سازی فرانت‌اند
در یک ترمینال وارد پوشه `frontend` شوید و پکیج‌ها را نصب کنید:
```powershell
cd frontend
npm install
```

## اجرای روزانه پروژه

### ۱. روشن کردن بک‌اند
یک ترمینال باز کنید و دستور زیر را بزنید:

```powershell
cd backend
php artisan serve
```

### ۲. روشن کردن فرانت‌اند
یک ترمینال **دیگر** باز کنید (ترمینال بک‌اند باید باز بماند) و دستور زیر را بزنید:

```powershell
cd frontend
npm run dev
```

سپس در مرورگر آدرس **http://localhost:5173** را باز کنید.

## ساختار فایل‌های پروژه

- **بک‌اند (`backend`):**
  - `routes/api.php`: مسیرهای API
  - `app/Http/Controllers/ServiceController.php`: کنترلر لیست خدمات
  - `app/Http/Controllers/CustomerController.php`: کنترلر ثبت‌نام و ورود مشتری (با رمز ۴ رقمی عددی)
  - `app/Http/Controllers/AppointmentController.php`: کنترلر ثبت، لیست و لغو نوبت‌ها (با بررسی ساعت کاری ۱۰ تا ۲۰)
- **فرانت‌اند (`frontend/src`):**
  - `App.jsx`: مدیریت صفحات اصلی برنامه
  - `components/JalaliDatePicker.jsx`: تقویم شمسی
  - `components/TimeSlotPicker.jsx`: کارت‌های قابل کلیک انتخاب ساعت (۱۰:۰۰ تا ۲۰:۰۰)
  - `pages/`: صفحات تفکیک‌شده (`RoleSelectPage`، `CustomerAuthPage`، `HomePage`، `BookingPage`، `OwnerPage`)
  - `utils/`: توابع کمکی تاریخ شمسی (`jalali.js`)، اعداد فارسی (`persian.js`) و ارتباط با سرور (`api.js`)
