# سیستم نوبت‌دهی آرایشگاه «پیرایش عارف»

این پروژه سیستم نوبت‌دهی آنلاین آرایشگاه است و از دو بخش تشکیل شده است:

| پوشه | بخش | تکنولوژی | آدرس اجرا |
|---|---|---|---|
| `backend` | بک‌اند و API | Laravel (PHP) + PostgreSQL | http://localhost:8000 |
| `frontend` | رابط کاربری (فرانت‌اند) | React + Vite | http://localhost:5173 |

---

## امکانات فعلی پروژه

- **طراحی و رابط کاربری:**
  - کاملاً راست‌چین (`RTL`) با فونت `B Nazanin`، پس‌زمینه سفید (`#ffffff`)، دکمه‌ها و هدرهای سبز (`rgb(13, 101, 45)`) و متون تیره خوانا (`#111827`).
  - مجهز به تقویم شمسی و نمایش فارسی اعداد و قیمت‌ها.
- **بخش مشتری:**
  - ایجاد حساب و ورود مشتری با نام (غیرتکراری، حداکثر ۴۰ کاراکتر) و شماره موبایل معتبر ۱۱ رقمی (`09...`).
  - مشاهده لیست خدمات آرایشگاه به همراه قیمت و مدت زمان واقعی هر خدمت.
  - ثبت نوبت با تقویم شمسی و بازه‌های زمانی ۳۰ دقیقه‌ای (از ساعت ۱۰:۰۰ تا ۲۰:۰۰).
  - جلوگیری خودکار از ثبت نوبت در تاریخ/ساعت گذشته و جلوگیری از رزرو تکراری یک ساعت.
- **بخش صاحب آرایشگاه:**
  - مشاهده لیست نوبت‌های هر روز به ترتیب ساعت با انتخاب تاریخ از روی تقویم شمسی.
  - امکان لغو نوبت بدون حذف از دیتابیس (تغییر وضعیت نوبت به «لغو شده» و آزاد شدن مجدد ساعت).

## پیش‌نیازها

- **Node.js** (برای اجرای فرانت‌اند)
- **PHP** و **Composer** (برای اجرای بک‌اند)
- **PostgreSQL** (دیتابیس با نام `barbershop`)

---

## راه‌اندازی اولیه (فقط بار اول)

### ۱. آماده‌سازی بک‌اند و دیتابیس
```powershell
cd backend
composer install
copy .env.example .env
php artisan key:generate
```
سپس مطمئن شوید اطلاعات اتصال به PostgreSQL در فایل `backend/.env` تنظیم است (`DB_DATABASE=barbershop`) و جداول و لیست خدمات را بسازید:
```powershell
php artisan migrate --seed
```

### ۲. آماده‌سازی فرانت‌اند
```powershell
cd frontend
npm install
```

## اجرای پروژه

### ۱. اجرای بک‌اند
یک ترمینال (PowerShell) باز کنید:

```powershell
cd backend
& "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\PHP.PHP.NTS.8.4_Microsoft.Winget.Source_8wekyb3d8bbwe\php.exe" artisan serve
```

### ۲. اجرای فرانت‌اند
یک ترمینال **دیگر** باز کنید (ترمینال بک‌اند باید باز بماند):

```powershell
cd frontend
npm run dev
```

سپس در مرورگر آدرس http://localhost:5173 را باز کنید.

## مسیرهای API بک‌اند

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/api/services` | دریافت لیست خدمات آرایشگاه |
| `POST` | `/api/customers/register` | ایجاد حساب مشتری جدید |
| `POST` | `/api/customers/login` | ورود مشتری قبلی |
| `GET` | `/api/customers/{id}` | دریافت اطلاعات مشتری با شناسه |
| `GET` | `/api/appointments?date=YYYY-MM-DD` | دریافت لیست نوبت‌های یک روز (مرتب بر اساس ساعت) |
| `POST` | `/api/appointments` | ثبت نوبت جدید توسط مشتری |
| `PATCH` | `/api/appointments/{id}/cancel` | لغو نوبت توسط صاحب آرایشگاه |
